03

Regeln

  1. Leeres Repo: Das Repo muss nach dem Start angelegt werden. Wir prüfen die Zeitstempel der Commits.
  2. Öffentlich: Das Repo liegt öffentlich auf GitHub und steht unter einer Open-Source-Lizenz.
  3. Solo oder Team: Allein oder im Team mit bis zu vier Leuten. Wohnsitz in Deutschland, Österreich oder der Schweiz.
  4. Werkzeuge frei: Jede Sprache und jedes Framework. KI-Tools sind erlaubt, aber du nennst sie in der README.
  5. Fremdcode: Bibliotheken ja. Fertige eigene Projekte von vorher einzukopieren ist nicht erlaubt. Erlaubt sind öffentliche Bibliotheken, Frameworks, offizielle Starter-Templates und Boilerplate. Im Zweifel: in der README nennen.
  6. Abgabe: README mit kurzer Beschreibung, Startanleitung und, wenn möglich, einem Demo-Link oder Video.
04

Anmeldung per Pull Request

Diese Seite speichert nichts über dich. Du meldest dich an, indem du eine kleine Datei in unser öffentliches Repo einreichst. Wird dein Pull Request gemergt, bist du dabei.

  1. Datei erzeugen: Trag unten deinen GitHub-Namen ein. Die Datei entsteht direkt in deinem Browser.
  2. Einreichen: Leg sie im Repo unter teilnehmer/ an und öffne einen Pull Request.
  3. Merge: Sobald der Pull Request gemergt ist, stehst du auf der Startliste. Alle Infos kommen danach über das Repo.
